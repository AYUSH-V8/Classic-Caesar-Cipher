# Caesar Cipher •  🔒

A slick, modern web app for the classic Caesar Cipher encryption/decryption.  
Dark/light mode, loading screen with incognito vibes, copy-to-clipboard, responsive design — perfect for quick secret messages with the squad.



## Features
- Encrypt & decrypt messages with any shift value (-25 to 25)
- Preserves spaces, numbers, punctuation — only letters get shifted
- Dark mode (default) + light mode toggle with smooth transition
- 2-second incognito-style loading screen with pulsing title & ghost icon
- One-click **Copy** button on result with "Copied!" toast notification
- Press **Enter** in the input box to encrypt instantly
- Clean, responsive design (works great on phone too)
- Gradient accents & hover effects for that premium feel


## How to Use
1. Type or paste your secret message
2. Pick your shift (positive = encrypt, negative = decrypt)
3. Hit **Encrypt →** or **← Decrypt**
4. Copy the result and send it — mission accomplished 🕵️‍♂️

Example:
- Original: `Hello Bro this is secret`
- Shift: `3`
- Encrypted: `Khoor Eur wklv lv vhfuhw`

## Tech Stack
- HTML5 + CSS (custom variables, gradients, transitions)
- Vanilla JavaScript (no frameworks — keep it lightweight)
- Clipboard API for copying
- Pure CSS animations for loading & hover effects
